Work

Weaver

2026 · novel-writing studio

Native ES modules · Supabase · Deno · Postgres · Cloudflare Pages

Case study → Open the app ↗ Product site ↗ Pricing ↗

A novel-writing studio that runs entirely in the browser. The author works on a raw manuscript alongside the finished book, and an AI panel proposes changes that enter the book only when the author accepts them. Work is stored locally first and synced to a private, compressed cloud vault.

The editor is built from scratch: a virtualised block engine that indexes a 1.8 MB manuscript in about 2.8 ms and keeps a whole novel scrollable on a phone.

RepoBundle

2026 · developer tool

React · TypeScript · Vite · Tailwind CSS · JSZip

Case study → Open the tool ↗ Source code ↗

A developer tool that turns a zipped repository into a single file ready for an AI model's context window. The source is preserved verbatim, with a generated file tree and per-language bundles alongside it.

Everything runs in the browser. The repository never leaves the machine, and large archives are processed in chunks so the tab stays responsive.

Capabilities

Editor engineering

The engine inside Weaver: a virtualised, block-indexed contenteditable built for book-length manuscripts.

Offline-first sync

Local-first storage with a gzip-compressed private vault and failover that reports honestly, running in Weaver.

AI integration

Four providers behind one interface in Weaver, with every model discovered at runtime rather than pinned.

Serverless backend

Eight Supabase edge functions on Deno carry Weaver's server side. Service keys never leave the platform.

Commercial plumbing

Gumroad as merchant of record, three tiers, and an admin console that handles fulfilment for Weaver.

CI & operations

Push-to-deploy through GitHub Actions on every repository, this one included.

Product & interface

Design systems, mobile layouts that keep every feature reachable, and brand marks drawn as SVG paths rather than fonts.

Developer tooling
